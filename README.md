# 📊 Customer Analytics Visualisation

## Overview

This project analyses customer visit behaviour across **45 retail outlets** using Python and interactive data visualisation techniques.

The objective was to identify business insights, uncover trends, compare outlet performance and communicate findings through effective visual storytelling.

---

## Project Objectives

- Explore customer visit behaviour
- Identify seasonal trends
- Detect outlet openings and closures
- Compare outlet performance
- Analyse relationships between operational variables
- Build interactive visualisations for business decision making

---

---

## Visualisations Included

- 📈 Bar Charts
- 📉 Interactive Line Charts
- 📦 Box Plots
- 🔥 Correlation Heatmaps
- 📊 Pair Plots
- 🕸 Radar Charts
- 🫧 Interactive Bubble Charts

---

## Key Findings

- Three outlets generated significantly higher customer traffic than all others.
- Most outlets showed stable customer demand throughout the year.
- Several outlets opened or closed during the analysis period.
- Staffing levels showed the strongest relationship with annual customer visits.
- Some medium-performing outlets had disproportionately high operational costs.
